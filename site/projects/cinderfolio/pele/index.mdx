## 流程图

```mermaid
flowchart LR
  subgraph Preview[实时预览]
    A[选择颜色] --> B{效果合适?}
    B -->|调整| A
  end
  B -->|确定| C[导出 CSS]
  C --> D([完成])
```

## 时序图

```mermaid
sequenceDiagram
  participant U as 读者
  participant W as 网页
  participant T as 主题
  U->>W: 选择品牌色
  W->>T: 计算色阶
  activate T
  T-->>W: 返回配色
  deactivate T
  W-->>U: 更新预览
  Note over U,W: 亮暗共享配色规则
```
