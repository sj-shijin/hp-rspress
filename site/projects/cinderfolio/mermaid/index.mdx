# Cinderfolio-Mermaid

[Mermaid](https://github.com/mermaid-js/mermaid) 将文本绘制为图表。选择图例后调整配色，下载对应的亮暗主题。

<Tab label="框线与结构">

<Tabs keepDOM={false}>

<Tab label="流程图">

```mermaid renderer=mermaid
flowchart LR
    accTitle: 文档发布流程
    A[文稿] --> B{检查}
    subgraph build[构建]
        B -->|通过| C[生成页面]
        C --> D[(归档)]
    end
    B -.->|修改| A
    D --> E[发布]
```

</Tab>

<Tab label="时序图">

```mermaid renderer=mermaid
sequenceDiagram
    participant R as 读者
    participant S as 服务
    R->>S: 请求文档
    activate S
    Note over R,S: 返回前检查版本
    alt 文档存在
        S-->>R: 页面内容
    else 尚未发布
        S-->>R: 状态提示
    end
    deactivate S
```

</Tab>

<Tab label="类图">

```mermaid renderer=mermaid
classDiagram
    class Document {
        +String title
        +render()
    }
    class Article {
        +String author
    }
    class Collection {
        +add(Document)
    }
    Document <|-- Article
    Collection o-- Document
```

</Tab>

<Tab label="状态图">

```mermaid renderer=mermaid
stateDiagram-v2
    direction LR
    [*] --> 草稿
    草稿 --> 审阅: 提交
    state 审阅 {
        校验 --> 确认
    }
    审阅 --> 草稿: 退回
    审阅 --> 发布: 通过
    发布 --> [*]
```

</Tab>

<Tab label="实体关系图">
